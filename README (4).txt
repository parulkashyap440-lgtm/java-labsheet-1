MCA203P - Object Oriented Programming Using Java
LAB SHEET-01

Files:
Q01 to Q20 are separate Java programs corresponding to questions 1-20.

How to run in VS Code:
1. Install JDK (17 or newer recommended).
2. Open this folder in VS Code.
3. Open any Qxx_*.java file.
4. Open Terminal -> New Terminal.
5. Compile:
   javac Q01_Display_Name_Age_College.java
6. Run:
   java Q01_Display_Name_Age_College

For another question, replace the filename/class name with the corresponding Qxx file.

OOP structure:
Each program uses a Java class containing the main() method. Programs that need reusable logic also use static methods. This keeps the solutions compatible with the OOP-based Java lab while directly following the questions in the lab sheet.
